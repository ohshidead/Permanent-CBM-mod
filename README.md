Permanent CBM mod


Potential Questions:

What is this?

A mod that adds CBMs that functional like a mutation, complete with a threshold bionic to cross.

---

How does it work?

Find the PCBMs around the place as you do and mix and match until you have all Facial, Ear, Torso, Arm, Leg, Hand, Feet replacements, then you can install the Mechanical Supremacy and surpass the weakness of flesh (And be able to install Mk II PCBMs)

---

I can install two bionics that are clearly for the same spot??

Id rather you didn't but cant stop you until some code changes (Hit me up if pull #7957 goes through!). If the bionic would conflict with another the game should warn you that it will conflict with the mutation that bionic provides so don't do that.

(mix and match, just not of the same type)
